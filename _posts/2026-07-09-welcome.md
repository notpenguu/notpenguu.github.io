This is my first post. Everything you see here is generated from a single Markdown
file — no HTML required.

## How this works

Each article lives in the `_posts` folder as a Markdown file named
`YYYY-MM-DD-title.md`. Jekyll turns it into a page automatically and lists it on the
home page, newest first.

## Formatting works out of the box

You can use **bold**, *italic*, [links](https://github.com), and lists:

- Point one
- Point two
- Point three

> Blockquotes look like this.

And code blocks:

```python
print("hello, world")
```

That's it — write Markdown, commit, done.
